# Services 디렉토리 규칙

서비스는 **도메인별**로 분류됩니다.

## 디렉토리 구조

| 도메인 | 설명 |
|--------|------|
| **Core/** | 앱 전역 핵심 서비스 (권한, 설정, 단축키) |
| **Editor/** | 에디터 탭 관리, 텍스트 엔진 |
| **FileSystem/** | 파일/폴더 CRUD, 변경 감시 |
| **Project/** | .weaveproj 프로젝트 관리 |

## 새 서비스 추가 시

1. **기존 도메인에 속하는 경우**: 해당 도메인 폴더에 추가
2. **새 도메인이 필요한 경우**: 폴더 생성 후 `claude.md` 작성
3. **여러 도메인에서 사용**: `Core/`에 배치

각 도메인의 상세 규칙은 해당 폴더의 `claude.md` 참조
