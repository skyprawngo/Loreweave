# 스크롤 모듈

`EditorScrollCoordinator`가 현재 화면 기준점 수집, 커서 노출, 화면 배치, 파일 위치 복원과 후속 레이아웃 보정을 소유한다. 서식 토글·글꼴 변경·외부 본문 변경의 기준은 `Event` 매핑에서 설정한다. 창 크기 변경은 이미 배치된 TextKit 위치를 사용한다. 검색 결과나 인라인 패널의 화면 노출도 이 모듈에 요청한다.

`EditorViewportResolver`는 저장된 행/문맥을 현재 원문에 대응시키는 순수 판정기다. `EditorViewportStore`는 파일별 기록 영속화와 파일 이동을 담당한다. 모듈은 원고 문자열이나 Undo 이력을 변경하지 않는다.

뷰는 활성 문서 확인과 이벤트 전달, 저장 시점만 조율한다. 기능 내부에서 픽셀 좌표·행 기준점을 다시 계산하거나 별도의 스크롤 보정을 추가하지 않는다. 네이티브 편집기의 문자 위치/행 사각형 조회는 입력·줄번호도 사용하는 기하 정보이며 정책을 소유하지 않는다.
